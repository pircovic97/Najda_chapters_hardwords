## 📖 Example

### Triage

**Definition:**
The process of determining the urgency and priority of medical cases.

**In Najda:**
The AI analyzes symptoms and classifies cases as urgent or consultation-level.

---

### Design System

**Definition:**
A collection of reusable design rules and components that ensure consistency.

**In Najda:**
The design system contains colors, typography, buttons, cards, and UI patterns shared across the platform.

## 🚀 Why This Repository Exists

Preparing for a defense is not only about presenting slides.

You should also be able to explain:

- Why a design decision was made
- What a technical term means
- How a methodology works
- How a feature relates to the project

This repository serves as a quick reference guide for those concepts.
